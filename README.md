A starling murmuration twisting into a giant curling wave above a hilltop
at dusk, built to excite make.fun's AI judge. The program copies the
bundled image byte-for-byte to the output directory.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.png` (1024×1024 JPEG) into the output directory.
